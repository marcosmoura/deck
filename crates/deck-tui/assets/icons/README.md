# Icons

The icons deck draws as images in Ghostty and kitty (see `docs/features/sidebar.md`): the
program icons, the space carets, the agent status marks and the unseen marker. Each icon is an
SVG source and a 64x64 8-bit alpha mask made from it once, outside the build. The masks are
embedded with `include_bytes!` (`deck-tui/src/graphics.rs`); nothing here is generated by
`cargo`, `just` or `mise`. `spinner.svg` and `spinner.mask` are for the rotating loader
(DECK-20 sub-spec 04).

Changes to the package's icons:

- `unseen` is `Circle` with `fill="currentColor"` added: the free set is stroke only.
- The stroke width is 2, not the 1.5 of the package: at the 16 to 20 pixels an icon takes in a
  terminal cell pair, 1.5 units are about one device pixel and `git`, the checkmarks and the
  carets come out faint; 2 reads clearly. The masks keep only the alpha channel, so the SVGs'
  `stroke="currentColor"` does not matter: icons are tinted at runtime.

## Making the SVGs and masks again

macOS, `rsvg-convert` 2.x from librsvg (any rasteriser that gives an RGBA PNG works), Python 3.
Run them in this directory, with `convert.py` and `mask.py` below saved in it (delete them
afterwards; they are not committed). The package is unpacked in `/tmp/hugeicons` and the
intermediate PNGs are written to `/tmp/<name>.png`:

```sh
mkdir -p /tmp/hugeicons && cd /tmp/hugeicons
npm pack @hugeicons/core-free-icons@4.4.0 && tar xzf hugeicons-core-free-icons-4.4.0.tgz
cd -
python3 -I convert.py /tmp/hugeicons/package . 2

for name in claude openai terminal editor git monitor remote build pager repl expanded collapsed spinner waiting idle quiet unseen new resume collapse_sidebar expand_sidebar opencode; do
  rsvg-convert -w 64 -h 64 --keep-aspect-ratio "$name.svg" -o "/tmp/$name.png"
  python3 -I mask.py "/tmp/$name.png" "$name.mask"
done
```

(`opencode.svg` is fetched from the URL above, not converted:
`curl -fL https://raw.githubusercontent.com/anomalyco/opencode/d84e1d7bb3711ffdd54494950c4af644155cb542/services/site/public/brand/files/opencode-logo-transparent-dark.svg -o opencode.svg`;
`convert.py` does not touch it.)

`convert.py` turns each `dist/esm/<Name>Icon.js` (a JavaScript array of SVG elements) into
`<file>.svg` with the stroke width given as its last argument and the viewBox cropped to
`1 1 22 22`: the 24-unit canvas minus its empty one-unit border, which a stroke of 2 reaches
exactly, so the drawing fills the mask edge to edge:

```python
import re, sys

ICONS = {
    "claude": "Claude", "openai": "ChatGpt", "terminal": "ComputerTerminal01", "editor": "PencilEdit02",
    "git": "GitBranch", "monitor": "DashboardSpeed02", "remote": "ArrowDataTransferHorizontal",
    "build": "Wrench01", "pager": "BookOpen01", "repl": "CodeSquare", "expanded": "ArrowDown01",
    "collapsed": "ArrowRight01", "spinner": "LoaderCircle", "waiting": "AlertCircle",
    "idle": "CheckmarkCircle02", "quiet": "Circle", "unseen": "Circle",
    "new": "PlusSign", "resume": "RotateClockwise",
    "collapse_sidebar": "ArrowLeftDouble", "expand_sidebar": "ArrowRightDouble",
}
ATTR = {"strokeLinecap": "stroke-linecap", "strokeLinejoin": "stroke-linejoin",
        "strokeWidth": "stroke-width", "fillRule": "fill-rule", "clipRule": "clip-rule"}
package, out, width = sys.argv[1:4]
for file, name in ICONS.items():
    src = open(f"{package}/dist/esm/{name}Icon.js").read()
    shapes = []
    for tag, attrs in re.findall(r'\["(\w+)", \{(.*?)\}\]', src):
        parts = []
        for key, value in re.findall(r'(\w+): "([^"]*)"', attrs):
            if key == "key":
                continue
            if key == "strokeWidth":
                value = width
            parts.append(f'{ATTR.get(key, key)}="{value}"')
        if file == "unseen":
            parts.append('fill="currentColor"')
        shapes.append(f"  <{tag} {' '.join(parts)}/>")
    svg = ('<svg xmlns="http://www.w3.org/2000/svg" width="22" height="22" viewBox="1 1 22 22" '
           'fill="none">\n' + "\n".join(shapes) + "\n</svg>\n")
    open(f"{out}/{file}.svg", "w").write(svg)
```

`rsvg-convert` fits the icon in 64x64 (OpenCode's, taller than wide, comes out 52x64).
`mask.py` decodes the PNG, takes its alpha channel, centres it in a 64x64 canvas (no margin)
and writes the 4096 bytes, row-major:

```python
import struct, sys, zlib


def alpha_of(path):
    data = open(path, "rb").read()
    assert data[:8] == b"\x89PNG\r\n\x1a\n"
    pos, idat = 8, b""
    while pos < len(data):
        n, kind = struct.unpack(">I4s", data[pos : pos + 8])
        body = data[pos + 8 : pos + 8 + n]
        pos += 12 + n
        if kind == b"IHDR":
            w, h, depth, ctype, _, _, interlace = struct.unpack(">IIBBBBB", body)
            assert depth == 8 and ctype == 6 and interlace == 0
        elif kind == b"IDAT":
            idat += body
    raw = zlib.decompress(idat)
    stride, bpp = w * 4, 4
    prev = bytearray(stride)
    rows = []
    for y in range(h):
        f = raw[y * (stride + 1)]
        line = bytearray(raw[y * (stride + 1) + 1 : (y + 1) * (stride + 1)])
        for i in range(stride):
            a = line[i - bpp] if i >= bpp else 0
            b = prev[i]
            c = prev[i - bpp] if i >= bpp else 0
            if f == 1:
                line[i] = (line[i] + a) & 255
            elif f == 2:
                line[i] = (line[i] + b) & 255
            elif f == 3:
                line[i] = (line[i] + ((a + b) >> 1)) & 255
            elif f == 4:
                p = a + b - c
                pa, pb, pc = abs(p - a), abs(p - b), abs(p - c)
                pr = a if pa <= pb and pa <= pc else (b if pb <= pc else c)
                line[i] = (line[i] + pr) & 255
        rows.append(line)
        prev = line
    return w, h, [bytes(r[3::4]) for r in rows]


w, h, rows = alpha_of(sys.argv[1])
out = bytearray(64 * 64)
ox, oy = (64 - w) // 2, (64 - h) // 2
for y, row in enumerate(rows):
    out[(oy + y) * 64 + ox : (oy + y) * 64 + ox + w] = row
open(sys.argv[2], "wb").write(out)
```

Compare the result with `cmp` against the committed masks; a different librsvg version can
differ by a few alpha values at the edges.
