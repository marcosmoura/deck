# Agent logos

The logos deck draws in place of the text icon of Claude Code, Codex and OpenCode
panels in Ghostty and kitty (see `docs/features/sidebar.md`). Each logo is an SVG source and
a 64x64 8-bit alpha mask made from it once, outside the build. The masks are embedded with
`include_bytes!`; nothing here is generated by `cargo`, `just` or `mise`.

of the SVGs does not matter. OpenCode's inner square has 28% opacity in its brand file and
keeps it in the mask.

## Making the masks again

The commands used (macOS, `rsvg-convert` 2.x from librsvg; any rasteriser that gives an
RGBA PNG works). Run them in this directory, with `mask.py` below saved next to them or
anywhere else:

```sh
curl -fLO https://cdn.jsdelivr.net/npm/simple-icons@15.22.0/icons/claude.svg
curl -fLO https://cdn.jsdelivr.net/npm/simple-icons@15.22.0/icons/openai.svg
curl -fL https://raw.githubusercontent.com/anomalyco/opencode/d84e1d7bb3711ffdd54494950c4af644155cb542/services/site/public/brand/files/opencode-logo-transparent-dark.svg -o opencode.svg

for name in claude openai opencode; do
  rsvg-convert -w 56 -h 56 --keep-aspect-ratio "$name.svg" -o "/tmp/$name.png"
  python3 -I mask.py "/tmp/$name.png" "$name.mask"
done
```

`rsvg-convert` fits the logo in 56x56 (OpenCode's, being taller than wide, comes out 45x56).
`mask.py` decodes the PNG, takes its alpha channel, centres it in a 64x64 canvas (a margin of
4 pixels around a 56x56 logo) and writes the 4096 bytes, row-major:

```python
import struct, sys, zlib


def alpha_of(path):
    data = open(path, "rb").read()
    assert data[:8] == b"\x89PNG\r\n\x1a\n"
    pos, idat = 8, b""
    while pos < len(data):
        n, kind = struct.unpack(">I4s", data[pos : pos + 8])
        body = data[pos + 8 : pos + 8 + n]
        pos += 12 + n
        if kind == b"IHDR":
            w, h, depth, ctype, _, _, interlace = struct.unpack(">IIBBBBB", body)
            assert depth == 8 and ctype == 6 and interlace == 0
        elif kind == b"IDAT":
            idat += body
    raw = zlib.decompress(idat)
    stride, bpp = w * 4, 4
    prev = bytearray(stride)
    rows = []
    for y in range(h):
        f = raw[y * (stride + 1)]
        line = bytearray(raw[y * (stride + 1) + 1 : (y + 1) * (stride + 1)])
        for i in range(stride):
            a = line[i - bpp] if i >= bpp else 0
            b = prev[i]
            c = prev[i - bpp] if i >= bpp else 0
            if f == 1:
                line[i] = (line[i] + a) & 255
            elif f == 2:
                line[i] = (line[i] + b) & 255
            elif f == 3:
                line[i] = (line[i] + ((a + b) >> 1)) & 255
            elif f == 4:
                p = a + b - c
                pa, pb, pc = abs(p - a), abs(p - b), abs(p - c)
                pr = a if pa <= pb and pa <= pc else (b if pb <= pc else c)
                line[i] = (line[i] + pr) & 255
        rows.append(line)
        prev = line
    return w, h, [bytes(r[3::4]) for r in rows]


w, h, rows = alpha_of(sys.argv[1])
out = bytearray(64 * 64)
ox, oy = (64 - w) // 2, (64 - h) // 2
for y, row in enumerate(rows):
    out[(oy + y) * 64 + ox : (oy + y) * 64 + ox + w] = row
open(sys.argv[2], "wb").write(out)
```

Compare the result with `cmp` against the committed masks; a different librsvg version can
differ by a few alpha values at the edges.
