# Features

Read when you need how a shipped feature behaves.

One page per feature, written by the work that ships it and kept current by every change to it. A spec records why and how a feature was planned; the page here describes how it works now.

- [Sessions](sessions.md): attach, detach, the default session, `deck ls`, `deck kill-server`, the exit messages.
- [Keys](keys.md): the prefix, the bindings and how to change them.
